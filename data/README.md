# Gulf Coast Estates — ZIP 36542 rental data

## Honesty note
Unit-level completeness at Airbnb / VRBO / MLS scale requires paid APIs and would run into **thousands** of listings area-wide. Manager public claims alone: Liquid Life **800+**, Brett/Robinson **1,800+**, Beachball **300+** (coast-wide portfolios, not all 36542).

This folder is a **best-effort public scrape** of:
- Named condo complexes in Gulf Shores / Fort Morgan (36542)
- Publicly listed unit/house rows from Liquid Life, Beachball, Harris, Seawind.com, Vacasa, owner sites, and local condo guides

Addresses are only included when found on a public page — **none invented**. Deduplicated by type + name.
